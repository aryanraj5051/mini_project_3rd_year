# FarmLink React Frontend

A polished React/Vite frontend for a direct farmer-to-buyer marketplace.

## Included
- Responsive modern UI
- Farmer / buyer view switch
- Marketplace search + category filters
- Product cards with farmer, stock, rating and price comparison
- Working cart drawer with quantities and demo order placement
- Farmer dashboard metrics
- Order management with demo status progression
- Market price comparison
- Weather preview
- Community posts + likes + post composer
- Responsive navigation and mobile menu
- No backend required for this frontend demo

## Run

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Notes
The original shared HTML/CSS/JS content was reorganized into a React single-page app and visually upgraded. Demo data is local state and can later be connected to your backend/database APIs.
